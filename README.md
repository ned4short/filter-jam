# Filter Jam

Free sliding block puzzle by Ned Games — slide the filter boxes and get the NED box out the van door. 40 levels; every par was found by a breadth-first solver.

Live: https://filterjam.nedwebservices.com/

Plain HTML/CSS/JS, no build step. Levels live in `levels.js` as `[horizontal, row-or-col, length, start]` per box; box 0 is the NED box.
